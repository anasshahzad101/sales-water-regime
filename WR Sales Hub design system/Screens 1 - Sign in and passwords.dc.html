Screens 1 · Sign in & passwords

Sign in, first-login password and change password. Every artboard is live, so you can click, type and set outcomes in place.

6.1

Sign in

One screen, three failure states. Sign-in is rate-limited on the server; the lock state counts down live.

Behaviour
  • Wrong credentials: fields go red, the alert says how many attempts are left. Never says which of the two was wrong.
  • Locked: the button is disabled and shows the remaining time (mm:ss). The server enforces it; the timer is only for display.
  • Deactivated: amber, not red. Names the admin to contact.
  • Password field: show/hide toggle with a 44px hit area. Uses autocomplete="current-password".

6.2

Set new password · Change password

First login forces a new password before anything else. Change password opens from the user menu.

Behaviour
  • Strength meter: 4 segments. Too short (under 8) → Weak → Good → Strong. Saving needs at least Weak and 8+ characters.
  • The confirm field shows “match” or “don’t match yet” while typing, and only turns red after a save attempt or once it’s as long as the new password.
  • After saving: toast, then go to My Week (or the Cockpit for the CEO).
